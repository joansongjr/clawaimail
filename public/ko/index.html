AI 에이전트를 위한 이메일

AI 에이전트에게 실제 이메일 주소를 제공하세요. 간단한 API로 이메일을 보내고, 받고, 관리할 수 있습니다.

import { ClawAIMail } from 'clawaimail';

const client = new ClawAIMail({ apiKey: 'pb_...' });

// 받은편지함 생성
const inbox = await client.createInbox({
  username: 'mybot'
}); // mybot@clawaimail.com

// 이메일 보내기
await client.sendMessage({
  inboxId: inbox.id,
  to: 'user@gmail.com',
  subject: 'Hello from AI',
  text: 'Your agent is ready.'
});

API 우선

Node.js와 Python SDK를 갖춘 RESTful API. 받은편지함 생성, 이메일 송수신을 프로그래밍 방식으로 처리합니다.

실시간

새 이메일 수신 시 WebSocket으로 즉시 알림. 이벤트 기반 아키텍처를 위한 Webhook 지원.

MCP 지원

MCP 서버 내장. OpenClaw, Claude Code, Cursor 및 모든 MCP 호환 AI 도구와 연동 가능.

커스텀 도메인

자체 도메인으로 에이전트 이메일을 운영하세요. 완전한 DNS 검증 및 관리 기능 제공.

스마트 기능

이메일 스레드, 라벨, 검색 등 다양한 기능. 에이전트가 대화를 관리하는 데 필요한 모든 것을 제공합니다.

확장성 설계

무료 받은편지함 3개부터 무제한까지 확장 가능. 검증된 이메일 인프라로 안정적 운영.
