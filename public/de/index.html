E-Mail für KI-Agenten

Geben Sie Ihren KI-Agenten echte E-Mail-Adressen. Senden, empfangen und verwalten Sie E-Mails über eine einfache API.

import { ClawAIMail } from 'clawaimail';

const client = new ClawAIMail({ apiKey: 'pb_...' });

// Posteingang erstellen
const inbox = await client.createInbox({
  username: 'mybot'
}); // mybot@clawaimail.com

// Eine E-Mail senden
await client.sendMessage({
  inboxId: inbox.id,
  to: 'user@gmail.com',
  subject: 'Hello from AI',
  text: 'Your agent is ready.'
});

API-First

RESTful API mit SDKs für Node.js und Python. Erstellen Sie Postingänge, senden und empfangen Sie E-Mails programmatisch.

Echtzeit

WebSocket-Benachrichtigungen bei eingehenden E-Mails. Webhook-Unterstützung für ereignisgesteuerte Architekturen.

MCP-kompatibel

Integrierter MCP-Server. Funktioniert mit OpenClaw, Claude Code, Cursor und jedem MCP-kompatiblen KI-Tool.

Eigene Domains

Verwenden Sie Ihre eigene Domain für Agenten-E-Mails. Vollständige DNS-Verifizierung und -Verwaltung.

Intelligente Funktionen

E-Mail-Threads, Labels, Suche und mehr. Alles, was Agenten zur Verwaltung von Konversationen benötigen.
