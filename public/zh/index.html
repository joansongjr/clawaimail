为 AI 智能体 打造的邮箱

为您的 AI 智能体提供真实的电子邮件地址。通过简单的 API 发送、接收和管理邮件。

import { ClawAIMail } from 'clawaimail';

const client = new ClawAIMail({ apiKey: 'pb_...' });

// 创建收件箱
const inbox = await client.createInbox({
  username: 'mybot'
}); // mybot@clawaimail.com

// 发送邮件
await client.sendMessage({
  inboxId: inbox.id,
  to: 'user@gmail.com',
  subject: 'Hello from AI',
  text: 'Your agent is ready.'
});

API 优先

提供 RESTful API 以及 Node.js 和 Python SDK。以编程方式创建收件箱、发送和接收邮件。

实时通知

新邮件到达时通过 WebSocket 即时通知。支持 Webhook，适用于事件驱动架构。

MCP 就绪

内置 MCP 服务器。兼容 OpenClaw、Claude Code、Cursor 及所有 MCP 兼容的 AI 工具。

自定义域名

使用您自己的域名创建智能体邮箱。完整的 DNS 验证和管理功能。

智能功能

邮件线程、标签、搜索等功能一应俱全。满足智能体管理对话的一切需求。
