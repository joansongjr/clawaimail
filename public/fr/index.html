Email pour Agents IA

Donnez de vraies adresses email à vos agents IA. Envoyez, recevez et gérez les emails via une API simple.

import { ClawAIMail } from 'clawaimail';

const client = new ClawAIMail({ apiKey: 'pb_...' });

// Créer une boîte de réception
const inbox = await client.createInbox({
  username: 'mybot'
}); // mybot@clawaimail.com

// Envoyer un email
await client.sendMessage({
  inboxId: inbox.id,
  to: 'user@gmail.com',
  subject: 'Hello from AI',
  text: 'Your agent is ready.'
});

API d'abord

API RESTful avec des SDKs pour Node.js et Python. Créez des boîtes de réception, envoyez et recevez des emails par programme.

Temps Réel

Notifications WebSocket à l'arrivée de nouveaux emails. Support des webhooks pour les architectures événementielles.

Compatible MCP

Serveur MCP intégré. Fonctionne avec OpenClaw, Claude Code, Cursor et tout outil IA compatible MCP.

Domaines Personnalisés

Utilisez votre propre domaine pour les emails de vos agents. Vérification et gestion DNS complètes.

Fonctions Intelligentes

Fils de discussion, étiquettes, recherche et plus encore. Tout ce dont les agents ont besoin pour gérer les conversations.

Conçu pour l'Échelle

De 3 boîtes de réception gratuites à l'illimité. Propulsé par une infrastructure email éprouvée.
