Correo para Agentes de IA

Dale a tus agentes de IA direcciones de correo electrónico reales. Envía, recibe y gestiona correos a través de una API sencilla.

import { ClawAIMail } from 'clawaimail';

const client = new ClawAIMail({ apiKey: 'pb_...' });

// Crear una bandeja de entrada
const inbox = await client.createInbox({
  username: 'mybot'
}); // mybot@clawaimail.com

// Enviar un correo electrónico
await client.sendMessage({
  inboxId: inbox.id,
  to: 'user@gmail.com',
  subject: 'Hello from AI',
  text: 'Your agent is ready.'
});

API Primero

API RESTful con SDKs para Node.js y Python. Crea bandejas de entrada, envía y recibe correos programáticamente.

Tiempo Real

Notificaciones WebSocket cuando llegan nuevos correos. Soporte de webhooks para arquitecturas basadas en eventos.

Compatible con MCP

Servidor MCP integrado. Funciona con OpenClaw, Claude Code, Cursor y cualquier herramienta de IA compatible con MCP.

Dominios Personalizados

Usa tu propio dominio para los correos de tus agentes. Verificación y gestión completa de DNS.

Funciones Inteligentes

Hilos de correo, etiquetas, búsqueda y más. Todo lo que los agentes necesitan para gestionar conversaciones.

Hecho para Escalar

Desde 3 bandejas de entrada gratuitas hasta ilimitadas. Respaldado por infraestructura de correo probada en batalla.
