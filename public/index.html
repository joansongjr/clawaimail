Email for AI Agents

Give your AI agents real email addresses. Send, receive, and manage emails through a simple API.

import { ClawAIMail } from 'clawaimail';

const client = new ClawAIMail({ apiKey: 'pb_...' });

// Create an inbox
const inbox = await client.createInbox({
  username: 'mybot'
}); // mybot@clawaimail.com

// Send an email
await client.sendMessage({
  inboxId: inbox.id,
  to: 'user@gmail.com',
  subject: 'Hello from AI',
  text: 'Your agent is ready.'
});

API-First
